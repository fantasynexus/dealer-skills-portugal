# Grelha de 100 pontos: Perfil de Empresa no Google

Lê isto antes de pontuar. Cada critério diz o que verificar, onde, que prova aceitar e o que vale total, parcial ou 0.

## Regras de pontuação

- Três respostas possíveis: **total**, **parcial** (o valor indicado) ou **0**. Sem prova, `N/V`.
- `N/V` (havia o que ver, faltou acesso) e **não se aplica** (a funcionalidade não existe para este perfil, categoria ou país) saem ambos do denominador.
- **Nota** = pontos obtidos ÷ pontos verificados × 100. **Cobertura** = pontos verificados ÷ pontos aplicáveis. Abaixo de 60 %, "nota indicativa".
- **Prova:** captura com data, link do perfil, texto copiado do perfil, ou dado da consola mostrado pelo gestor.
- **Referência de comparação:** a mediana de três a cinco concorrentes semelhantes da mesma zona (mesmo tipo de stand, mesma área de influência). Os limiares relativos abaixo são método desta skill, não regras da Google.
- Na dúvida entre dois valores, escolhe o mais baixo e diz porquê.

### Achados críticos (assinalar sempre, seja qual for a nota)

Perfil suspenso ou restrito; ninguém no stand é proprietário; perfil duplicado activo; "fechado" indevido; morada ou pin que levam a outro sítio; nome com palavras acrescentadas; sinais de avaliações de colaboradores ou compradas; alterações da Google pendentes que mudam dados essenciais.

## Grupos com várias instalações

Pontua cada instalação em separado. Depois, uma tabela de consistência, sem nota própria:

| Instalação | Padrão do nome | Categoria principal | Telefone | Horário e especiais | Taxa de resposta | Fotografia mais recente | Duplicados |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Assinala: nomes sem padrão comum, categorias diferentes para a mesma actividade, telefones de uma instalação noutra, uma instalação sem respostas enquanto as outras respondem. Não misturas avaliações nem contactos de instalações diferentes. Um perfil só existe para uma instalação com sinalética e atendimento no horário; departamentos (oficina) e marcas com perfil próprio só depois de confirmar as directrizes actuais da Google.
